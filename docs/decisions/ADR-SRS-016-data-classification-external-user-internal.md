# ADR-SRS-016: 外部I/F・ユーザー入力・内部データの三分類規約とSRS構造再編

| 状態 | 採用・未実装 |
| 決定日 | 2026-06-05 |

## Context

SRS の「6. 外部インターフェース仕様」にはシステムが管理する内部データ（ローカルキャッシュ・N03 前処理済みファイル・localStorage 編集内容）やユーザー入力（コマンド引数・HTML ビューア入力）が混在していた。また、「2.2.2 FR 間中間データ」として内部データの一部をデータ辞書セクションに置いていたが、「辞書」の性格と合わない配置だった。

これらを整理するための分類基準が文書化されておらず、新たに項目を追加するたびに分類が曖昧になる問題があった。

## Decision

以下の三分類を定義し、SRS の章構成を再編する。

### 三分類の定義

| 分類 | 定義 |
|---|---|
| 外部I/F（外部インターフェース） | システム境界の外に存在するもの（システムが管理・制御できないもの）、またはユーザーが外部で利用するためにシステムが出力する成果物 |
| ユーザー入力 | ユーザーがツールに与える入力 |
| 内部データ | システムが生成・管理するもの（メモリ・一時ファイル・永続キャッシュ・ブラウザ永続化を含む） |

**ローカルキャッシュは内部データ**（`$DATA_DIR/tiles/` はシステムが書き込み・削除・管理できるため外部I/Fの定義に該当しない）。

### SRS 構造変更

| 旧 | 新 | 変更内容 |
|---|---|---|
| 2.2.2 FR 間中間データ | 廃止 → 7.2 へ移設 | |
| 6. 外部インターフェース仕様 | 6.（変更なし） | 外部I/F のみに純化 |
| 6.1 入出力: 地理院標高タイル（取得・ローカルキャッシュ） | 6.1 入力: 地理院標高タイル（リモート取得元） | ローカルキャッシュ保存先・入出力役割を削除（7.2 へ） |
| 6.10 入力: N03 前処理済みファイル（FR-017 生成） | 7.2.1 N03 前処理済みファイル詳細仕様 | 内部データに移設 |
| 6.14 入力: コマンド引数 | 7.1.1 コマンド引数 | ユーザー入力に移設 |
| 6.16 入力: HTML ビューア上のユーザー入力 | 7.1.2 HTML ビューア上のユーザー入力 | ユーザー入力に移設 |
| 6.17 永続化: localStorage 編集内容 | 7.2.2 localStorage 編集内容詳細仕様 | 内部データに移設 |
| 7. 外部システム依存関係・環境 | 8. | リナンバリング |

**6.8 標高地形図 PNG は外部I/F のまま**（ユーザーが目視確認のためシステム外で利用する成果物として扱う）。

## Alternatives

**案A: 内部データを 2.2.3 として保持**

2.2 データ辞書の中に「2.2.3 内部データ（主要ファイル）」を追加する案。

却下理由: 2.2 の冒頭説明が「FR-XXX でパラメータ・FR 間中間データを参照するときは」と示す通り、FR の入出力に関わる辞書的な性格を持つセクションである。ローカルキャッシュ（永続ファイル）や localStorage（ブラウザ永続化）まで含めると性格が不明確になる。

**案B: 6 内にサブセクション化（6a. 内部データ仕様）**

セクション6の中に「6a.」や「6.0」として内部データ用サブセクションを設ける案。

却下理由: 「6. 外部インターフェース仕様」という章タイトルと矛盾する。章レベルで外部I/F と内部データが混在し、分類が伝わらない。

**案C: 採用（7 を新設して分離）**

7.1 ユーザー入力・7.2 内部データとして独立セクションを設ける。章タイトル「7. ユーザー入力と内部データ」で分類が明示され、6 と 7 の責務が明確に分かれる。

## Consequences

- SRS の章番号リナンバリング（7→8, 8→9, 9→10）により、既存ドキュメントや既存 ADR 内の参照リンクに更新が必要な場合がある
- 今後 SRS に項目を追加する際の分類基準として機能する（[CLAUDE.md](../../CLAUDE.md) の「外部I/F・ユーザー入力・内部データの分類ルール」も参照）
- 6.8（標高地形図 PNG）など、「システムが外部から取得するが、取得はユーザーが手動」というケースの分類は引き続き個別判断が必要
- 旧 6.15（N03 行政区域データ（生））は、FR-017 レビュー（2026-06-05）で **「ユーザー入力」** に分類されて [7.1.3](../20_SRS.md#713-n03-行政区域-zip) に移設された（ユーザーが ZIP を手動配置するファイルはツールへの入力という解釈）

Decision で計画した「7. ユーザー入力と内部データ」（7.1 ユーザー入力一覧・7.2 内部データ一覧）は、実装時に独立2章へ変更された。
