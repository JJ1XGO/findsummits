# ADR-SRS-020: FR-006 出力を per-peak 対応レコード（ピーク候補・コル情報リスト）に一本化

| 状態 | 採用・未実装 |
| 決定日 | 2026-06-14 |

## Context

[FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算)（コル検出・プロミネンス計算）の出力は当初「コル情報のリスト」として定義され、[FR-007](../20_SRS.md#fr-007-per-mesh-csv-出力プロミネンス閾値適用)（per-mesh CSV 出力）と [FR-016](../20_SRS.md#fr-016-ピーク域ポリゴン生成)（ピーク域ポリゴン生成）には「ピーク候補リスト」（[FR-005](../20_SRS.md#fr-005-ピーク候補検出) 出力）と「コル情報」（[FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) 出力）の2入力を別々に持たせていた。

[FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) レビューで以下の問題が指摘された:

1. **ジョインキーが未定義**: [FR-007](../20_SRS.md#fr-007-per-mesh-csv-出力プロミネンス閾値適用)・[FR-016](../20_SRS.md#fr-016-ピーク域ポリゴン生成) がピーク候補リストとコル情報を結合する際のキーが SRS に記述されていない
2. **3成分同時接触エッジケース**: 同一コルピクセルで3成分以上が同時接触する稀なケースでは、per-col リストでは1コルが複数ピークに対応しうるため曖昧。per-peak レコードなら一意に解決する
3. **アルゴリズムの出力単位と不一致**: 標高降順 Union-Find 走査でのコル検出は「1回のマージ＝1ピークの Key コル確定」という 1:1 対応を自然に生む。この単位を分割して下流で再結合させることに合理性がない

## Decision

[FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) の出力を **「ピーク候補・コル情報リスト」**（1レコード＝1ピーク＋その Key コル）に一本化する。

1レコードのフィールド構成:

- ピーク座標（解析範囲標高グリッド上のピクセル座標。緯度経度変換は [FR-007](../20_SRS.md#fr-007-per-mesh-csv-出力プロミネンス閾値適用) が実施）
- ピーク標高（m）
- コル座標（`col_lat`/`col_lon`・[FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) が緯度経度変換済み）
- コル標高（m）
- プロミネンス（m）
- `key_col_resolved`（bool: グリッド最外周 1px 海面ボーダーへの接触有無）
- `col_margin_px`（コルからグリッド端4辺までの最短距離・診断用）

[FR-016](../20_SRS.md#fr-016-ピーク域ポリゴン生成) の入力から独立した「ピーク候補リスト」（[FR-005](../20_SRS.md#fr-005-ピーク候補検出) 出力）を削除し、「ピーク候補・コル情報リスト」一本で両 FR（[FR-007](../20_SRS.md#fr-007-per-mesh-csv-出力プロミネンス閾値適用)・[FR-016](../20_SRS.md#fr-016-ピーク域ポリゴン生成)）のピーク情報要求を充足する。

## Alternatives

- **独立リスト維持＋ジョインキー定義**: 連結成分IDをジョインキーとして明示する案。ただし3成分同時接触エッジケースでは per-col リストのレコード数とピーク数が一致しなくなる可能性があり、ジョインロジックが複雑化する。アルゴリズムの自然な出力単位とも乖離するため却下
- **[FR-005](../20_SRS.md#fr-005-ピーク候補検出) 出力にコル情報を統合（[FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) を廃止）**: [FR-005](../20_SRS.md#fr-005-ピーク候補検出) と [FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) は同一走査ループを共有するが、「ピーク候補検出」と「コル検出・プロミネンス計算」は概念的に分離した責務であり、SRS 上の FR 分割を維持することにする

## Consequences

- [FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) 出力・[FR-007](../20_SRS.md#fr-007-per-mesh-csv-出力プロミネンス閾値適用) 入力・[FR-016](../20_SRS.md#fr-016-ピーク域ポリゴン生成) 入力の SRS 記述を更新する
- GLOSSARY の内部トランザクション例示（[FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) 出力名称）を追従する
- `docs/CLAUDE.md` の分類ルール表の例示名称を追従する
- コルの帰属（「2成分が接触したコルは標高の低い方のピークの Key コルになる」）は本レコード構造に内包されるため、SRS [FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) 説明に1文明記する
