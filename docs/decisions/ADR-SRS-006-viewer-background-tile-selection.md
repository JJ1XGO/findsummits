# ADR-SRS-006: HTML ビューアの背景タイル選定

| 状態 | 採用・実装済み |
| 決定日 | 2026-05-13 |

## Context

HTML ビューア（[FR-013](../20_SRS.md#fr-013-html-ビューア生成)）の背景地図として、日本の山岳地帯でサミット候補を目視確認しやすいタイルが必要。
要件は次のとおり：

- 山岳部での視認性（等高線・地形情報が豊富）
- API キー不要または入手が容易
- 利用規約上、非商用・個人利用が無料
- Leaflet.js から標準的な XYZ タイル形式で利用可能

## Decision

以下の3タイルを採用する：

| タイル | URL | 等高線 | API キー |
|---|---|---|---|
| 国土地理院 標準地図 | `cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png` | あり | 不要 |
| OSM | `{s}.tile.openstreetmap.org/{z}/{x}/{y}.png` | なし | 不要 |
| OpenTopoMap | `{s}.tile.opentopomap.org/{z}/{x}/{y}.png` | あり | 不要 |

## Alternatives

検討したが採用しなかった選択肢：

**Thunderforest Outdoors**  
等高線入りで日本対応・視認性が高く最有力の代替候補。ただし API キーの取得・管理が必要（無料枠 15万タイル/月）。本プロジェクトの用途（申請者 1 名のローカル作業）では枠内に収まると考えられるが、キー管理のコストを避けるため見送り。将来 OSM を差し替える候補として残す。

**ESRI World Topo Map**  
API キー不要・等高線入りで魅力的だが、Esri が deprecated（廃止）を宣言しており今後タイルが消滅する可能性がある。長期利用に不向きとして採用しない。

**Stadia Maps（旧 Stamen Terrain）**  
API キーが必要なうえ、日本エリアの等高線データが薄く山岳確認用途に適さない。

**CyclOSM**  
API キー不要だが等高線なし・サイクリング特化のスタイルのため不採用。

**地理院タイル 陰影起伏図**  
API キー不要・日本専用で地形の凹凸が視認しやすい。等高線ではなく陰影表現のため、等高線による標高確認には不向き。将来オーバーレイとして追加を検討する余地はある。

## Consequences

- OSM は等高線なしで山岳部の視認性が低いが、街や道路の確認用として補完的に残す。等高線は地理院標高タイルを Canvas 描画する独自オーバーレイで補完可能（[ADR-SRS-015](ADR-SRS-015-contour-overlay.md)）
- OpenTopoMap は等高線入りだが配色がやや見づらい。Thunderforest Outdoors が利用可能になった場合の差し替え候補
- 国土地理院 標準地図は等高線・山名・登山道が入っており、国内山岳確認の主力として使う想定
- 全タイルに帰属表示（attribution）リンクを付与して公開 URL からアクセスされても規約を満たす状態にしている
