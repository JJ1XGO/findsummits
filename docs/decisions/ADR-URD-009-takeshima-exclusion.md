# ADR-URD-009: 竹島サミット候補の除外方式

| 状態 | 採用・未実装 |
| 決定日 | 2026-05-17 |

---

## Context

URD [UR-001](../10_URD.md#ur-001) は「北方領土および竹島に所在するサミット候補は除く」と規定している。

**竹島の SOTA 上の位置づけ:**  
竹島（島根県、北緯37.24°・東経131.86°）は韓国が実効支配しており、
SOTA データベース（summitslist.csv）では韓国アソシエーション（HL）の
`HL/GB-430`（大韓봉 / Daehanbong、168m）として登録されている。
SOTA 日本支部（JA）のサミットとしては登録されておらず、日本支部の管轄外である。

**1次メッシュ上の位置:**  
竹島は 1次メッシュコード **5531**（36.667〜37.333°N, 131〜132°E）に含まれる。
この範囲は日本海上であり、JA サミット・日本本土は一切存在しない（summitslist.csv で確認済み）。
そのため、メッシュ 5531 を解析対象から除外しても日本のサミット候補を取りこぼすリスクはない。

**N03 データによる除外が適用できない理由:**  
北方領土（ADR-URD-005 参照）は「北方領土問題等の解決の促進のための特別措置に関する法律（1982年）」に基づき
6村が日本の正式行政区域として登録されており、N03 データに独立ポリゴンが存在する。
竹島には相当する立法がなく、N03 データへの独立ポリゴンの収録が確認できないため、
ADR-URD-005 と同様の N03 コードベース除外は適用しない。

## Decision

`params/mesh_list_japan.txt` からメッシュコード **5531** を削除することで竹島を解析対象から除外する。

これにより、タイル事前取得（[FR-001](../20_SRS.md#fr-001-標高タイル事前取得)）・C エンジン解析ともにメッシュ 5531 を処理しない。
N03 ポリゴンベースのタイルマスク（ADR-URD-005 の方式）は竹島に対しては使用しない。

## Alternatives

| 案 | 却下理由 |
|---|---|
| 座標 bounding box によるハードコード除外 | 実装が増える割に、メッシュ 5531 に日本領土がないため利得がない |
| N03 行政区域コードによる除外（ADR-URD-005 と同方式） | 竹島が N03 に独立ポリゴンとして収録されていることが確認できないため採用しない |
| summitslist.csv 突合フェーズで HL サミットを除外 | ピーク候補が per-mesh CSV・統合 CSV に混入した後のポストフィルタであり、除外タイミングが遅い |

## Consequences

- `params/mesh_list_japan.txt` から 5531 を 1 行削除するのみ（実装コスト最小）
- [FR-001](../20_SRS.md#fr-001-標高タイル事前取得)（タイル事前取得）・findsummits（C エンジン）のコード変更は不要
- SRS の前提・制約・スコープ外・関連 FR への竹島記述追加が別途必要（ISSUE 登録済み）
