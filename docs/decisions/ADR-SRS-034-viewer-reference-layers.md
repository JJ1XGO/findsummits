# ADR-SRS-034: HTML ビューアの補助参照レイヤー（1次メッシュグリッド・基準点）の追加

| 状態 | 採用・未実装 |
| 決定日 | 2026-06-21 |

## Context

`docs/mockup/viewer_mockup.html`（SRS に先行して実機検証で仕様を固めるモック）での検証を経て、
HTML ビューア（[FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様)）に 2 つの補助参照レイヤーを追加することを決めた。

- **1次メッシュグリッド**: 日本国土の1次メッシュ境界。解析単位（メッシュ）と成果物の位置関係を目視確認する補助。
- **基準点レイヤー**: 国土地理院の基準点（電子基準点・一〜三等三角点）。地形・座標の妥当性確認（解析座標と公的測量点の突き合わせ）の補助。

いずれも [UR-006](../10_URD.md#ur-006)（目視確認用ビューア＝エビデンス／観測可能性）に資する。
論点は主に **基準点レイヤーが新規の外部データ源（地理院基準点タイル `xyz/cp/{z}/{x}/{y}.geojson`）を導入する**こと。
1次メッシュグリッドは自前のメッシュコード定義から描画でき、外部依存を増やさない。

## Decision

1. **両レイヤーを [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の正式機能として追加する**（いずれもレイヤーコントロールで ON/OFF 可能・デフォルト OFF）。
   - 1次メッシュグリッド: 一定ズーム以上でメッシュコードのラベルを表示。
   - 基準点レイヤー: 種別ごとに配色し、点名・基準点種別・基準点コードを popup 表示。表示範囲のタイルをブラウザから実行時取得する。
2. **基準点タイルを新規外部データ源として文書化する**。
   - `ref/SOURCES.md` に「国土地理院 基準点タイル」エントリを追加（取得 URL・利用規約・帰属表示義務・利用形態）。
   - `docs/00_GLOSSARY.md` に「基準点」用語を追加。
   - 帰属表示: 地理院由来のため提供元は既存の `© 国土地理院` と同一。基準点レイヤー ON 時はビューアの帰属表示へ基準点データの出典として `国土地理院` を併記する（[UR-011](../10_URD.md#ur-011)・[ADR-URD-014](ADR-URD-014-gsi-tile-attribution-policy.md) の帰属方針に整合）。
3. **描画機構（タイル取得・色分け・pane 等）は HLD に委ねる**。SRS（[FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様)）には観測可能な挙動のみ記載する。

## Alternatives

- **基準点レイヤーをモック専用にとどめ SRS に含めない**: 外部データ源の追加を避けられるが、座標・地形の妥当性確認というエビデンス用途の価値を捨てることになる。ユーザー判断で採用に至った（両レイヤーとも正式機能化）。
- **1次メッシュグリッドのみ採用し基準点は保留**: 外部源追加を先送りできるが、同時に確定できる検証フィードバックを分割するため不採用。
- **基準点を静的データとして同梱**: タイルを事前取得して同梱する案。全国分はデータ量が大きく、リポジトリに含めない方針（標高タイル同様）と整合しないため不採用。実行時取得とする。

## Consequences

- HTML ビューアの外部依存に地理院基準点タイル（ベクトルタイル）が加わる。オフライン（`file://`）でも基準点レイヤーを ON にした場合はネットワーク取得が必要（OFF なら不要）。
- `ref/SOURCES.md`・`docs/00_GLOSSARY.md`・[FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の帰属表示記述を本 ADR と整合させる（本コミットで実施）。
- 本番ビューア（[FR-013](../20_SRS.md#fr-013-html-ビューア生成) 生成）への実装は別タスク（HLD・実装フェーズ）で行う。
