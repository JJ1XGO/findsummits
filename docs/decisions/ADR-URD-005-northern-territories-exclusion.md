# ADR-URD-005: 北方領土サミット候補の除外方式

| 項目 | 内容 |
|---|---|
| 状態 | 採用・未実装 |
| 決定日 | 2026-05-12 |

---

## Context

URD [UR-001](../10_URD.md#ur-001) は「北方領土に所在するサミット候補は除く」と規定している。
一方、国土数値情報 N03-2026（行政区域データ）を調査した結果、以下の事実が判明した。

**北方領土の行政的位置づけ:**  
「北方領土問題等の解決の促進のための特別措置に関する法律」（1982年）に基づき、
択捉島・国後島・色丹島の各村は現在も日本の正式な行政区域として登録されている。

| 島 | 村名 | 市区町村コード（N03_007） |
|---|---|---|
| 色丹島 | 色丹郡色丹村 | 01695 |
| 国後島 | 国後郡泊村 | 01696 |
| 国後島 | 国後郡留夜別村 | 01697 |
| 択捉島 | 択捉郡留別村 | 01698 |
| 択捉島 | 紗那郡紗那村 | 01699 |
| 択捉島 | 蘂取郡蘂取村 | 01700 |

N03-20260101.geojson の実データで確認済み（2026-06-05）。
総務省の市区町村コード表が正式な出典。歯舞群島は1959年に根室市へ合併済みのため対象外。

**N03 ポジティブフィルタが機能しない理由:**  
上記6村が N03-2026 に正式ポリゴンとして収録されているため、
「N03 ポリゴン内 = 日本行政区域 = 解析対象」というポジティブフィルタ方式では
北方領土のピーク候補を除外できない。市区町村コードによる明示的な指定除外が必要。

**SOTA との整合:**  
SOTA 日本支部の既存サミットリスト（`ref/summitslist.csv`）は北方領土のサミットを
収録していない。本ツールの目的である申請リスト更新においても北方領土は対象外とする。

## Decision

以下の3ステップで北方領土を除外する:

1. **識別（FR-017）**: N03-2026.geojson の N03_007 属性が 01695〜01700 に一致するポリゴンを
   北方領土除外対象として識別し、`N03-2026_excluded_tiles.txt` を生成する。
   このファイルはズームレベル15の Web Mercator タイル座標（x, y の整数ペア）のリストであり、
   対象ポリゴン内に中心点が含まれる全タイルを列挙する。

2. **除外（FR-001）**: `N03-2026_excluded_tiles.txt` を FR-001（タイル事前取得）が読み込み、
   リスト内のタイル（ズームレベル 15 の x/y 整数ペア）への HTTP リクエストを発行しない。
   これにより北方領土タイルがローカルキャッシュに存在せず、ピーク候補は
   フェーズ2以降に一切流れ込まない（詳細: [ADR-SRS-018](ADR-SRS-018-northern-territories-skip-at-tile-fetch.md)。
   旧方式では FR-003（C エンジン）が NODATA 扱いにする方式だったが、
   タイル取得段階での除外に変更済み）。

3. **フォールバック**: `N03-2026_excluded_tiles.txt` が存在しない場合は FR-001 がエラー終了する
   （詳細: [ADR-SRS-018](ADR-SRS-018-northern-territories-skip-at-tile-fetch.md)。
   旧方式では除外スキップで続行する方針だったが、FR-017 が FR-001 の必須前提に変更された）。

**タイル単位除外で十分な精度が得られる理由（本土を誤除外しないこと）:**  
北方領土4島はオホーツク海・根室海峡によって本土と完全に隔離された島嶼群であり、
本土との陸地境界が存在しない。ズームレベル15タイル（辺長 ~1.2km）の単位であれば、
島内タイルと本土タイルが地理的に重複することはない。よって北方領土除外タイルリストに
本土タイルが誤って含まれるリスクはない。

**取り逃しタイルのリスク評価（北方領土を取り逃さないこと）:**  
ポリゴン中心点判定では、ポリゴン端の海岸線付近のタイル（中心点が海側にずれるタイル）が
除外リストに含まれない可能性がある。論理的には:

- 取り逃しタイル ≒ 海岸線付近のタイル ≒ 標高が低い領域
- サミット検出はプロミネンス 150m 以上のピークが対象
- よって取り逃しが起きてもサミット検出結果に影響しない可能性が高い

**実データ検証結果（2026-06-05）:**  
`analysis/verify_northern_territories_tile_isolation.py` により N03-20260101.geojson を使って
Z15 タイル交差ベースで検証した結果:

- 北方領土6村タイル数: 7,321
- 北海道全フィーチャ（歯舞群島含む）との衝突タイル数: **0**
- 最近接距離: 約 17.9 km（Z15 タイル辺長 ~1.2 km の約 15 タイル分）

「タイル単位除外で本土を誤除外しない」は実データで確認済み。
取り逃しタイルのリスク（「北方領土を取り逃さない」方向の論証）については、
タイル単位検証で衝突 0 件が確認されたため、sea coastal fringe のリスクが
サミット検出結果に影響しないことは地理的事実（17.9 km の海峡による分離）から確定的といえる。

## Alternatives

| 案 | 却下理由 |
|---|---|
| N03 ポジティブフィルタ（ポリゴン外を除外） | 北方領土の6村が N03 に収録されているため機能しない |
| FR-009（merge.py）でのポストフィルタ | ピーク候補が per-mesh CSV・統合 CSV に混入した状態のまま後段まで流れる。FR-003 でのプレフィルタより検出段階が遅すぎる |
| 座標範囲（bounding box）によるハードコード除外 | 択捉島・国後島の経度は根室市と重複する範囲を含む可能性があり、ハードコードの境界値が誤って本土を除外するリスクがある。N03 コードによる識別の方が正確でメンテナンス性も高い |
| C エンジン内でのポリゴン containment 判定 | C エンジンに geometry ライブラリを追加する必要があり、アーキテクチャの複雑性が増す。事前生成タイルリストの方式で同等の結果が得られる |

## Consequences

- **FR-017**: preprocess_pref_boundaries.py の責務が拡張される。
  既存出力（`N03-2026_regions.geojson`）に加え、
  `N03-2026_excluded_tiles.txt` および `N03-2026_municipalities.geojson` を追加出力する
- **FR-001**: `N03-2026_excluded_tiles.txt` を読み込み、リスト内の Z15 タイルへの HTTP リクエストを
  発行しない。これにより北方領土タイルがローカルキャッシュに存在せず、ピーク候補はフェーズ2以降に
  一切流れ込まない（詳細: [ADR-SRS-018](ADR-SRS-018-northern-territories-skip-at-tile-fetch.md)）
- **市区町村名（FR-009 連携）**: FR-017 の拡張で生成する
  `N03-2026_municipalities.geojson` は FR-009 での市区町村名判定にも使用する
  （所在地の申請書記載レベルを都道府県から市区町村に向上させる）
