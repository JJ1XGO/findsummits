# ADR-SRS-002: DEM 階層フォールバックと DEM1a 不採用

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-04-20 頃 |

---

## Context

国土地理院の DEM タイルには複数の精度ランクがある。  
カバレッジに欠損があるため、単一 DEM に依存するとNODATAが増加する。  
また DEM1a（1m 解像度）は存在するが、データ量が DEM5 の 25 倍になる。

## Decision

標高取得の優先順位:

1. **DEM5a** (5m 解像度) — 最優先
2. **DEM5b** — DEM5a が NODATA の場合
3. **DEM5c** — DEM5b も NODATA の場合
4. **DEM10b** (10m 解像度) — DEM5c も NODATA の場合

**DEM1a（1m 解像度）は採用しない。**

## Alternatives

| 案 | 却下理由 |
|---|---|
| DEM1a を最優先 | データ量が DEM5 の 25 倍。プロミネンス 150m 判定に必要な精度向上はほぼない。 |
| DEM10 のみ | 精度不足（10m 解像度では山頂標高の誤差が大きくなりうる） |

## Consequences

- DEM5 が存在しないタイルでも DEM10 でフォールバックするため、全国解析が可能
- DEM10b が GSI 側で未整備のタイルは NODATA（`-9999.0f`）として扱い、解析続行
- 欠損は南部メッシュ（35.7°N 以南）に集中することが実測で確認されている
