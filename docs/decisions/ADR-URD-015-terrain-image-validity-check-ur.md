# ADR-URD-015: 妥当性確認用画像の UR 化

| 状態 | 採用・未実装 |
| 決定日 | 2026-06-08 |

## Context

[FR-015](../20_SRS.md#fr-015-標高地形図出力)（標高地形図出力）は、解析に使う標高データの読み込み正常性を解析実行前に視覚確認できるようにするための機能である。しかし URD に [FR-015](../20_SRS.md#fr-015-標高地形図出力) に対応するユーザー要件が存在しなかった（[FR-015](../20_SRS.md#fr-015-標高地形図出力) は [UR-001](../10_URD.md#ur-001) に紐付けられていたが、[UR-001](../10_URD.md#ur-001) の主旨は「日本全国のピークを網羅的に検出できること」であり、妥当性確認用画像の生成を意図したものではない）。

SRS の FR には対応 UR を明記する規約があるため、[FR-015](../20_SRS.md#fr-015-標高地形図出力) に対応する UR を URD に新設することが必要となった。

なお、[UR-006](../10_URD.md#ur-006) は「目視確認用 GeoJSON と HTML ビューア」を要求しており、地図上での精密な目視検証（サミット候補・コル座標・プロミネンスの確認）を対象としている。[FR-015](../20_SRS.md#fr-015-標高地形図出力) が対象とする「解析データの妥当性確認（標高データが正常に読み込まれているか）」は [UR-006](../10_URD.md#ur-006) とは役割が異なる。

## Decision

[UR-012](../10_URD.md#ur-012) として以下の要件を URD に新設する:

> [UR-012](../10_URD.md#ur-012): 解析対象範囲とその範囲内の地形の妥当性を目視確認できる画像を生成できること

**「妥当性確認（[UR-012](../10_URD.md#ur-012)）」と「精密な目視検証（[UR-006](../10_URD.md#ur-006)）」の役割分担**:

| | [FR-015](../20_SRS.md#fr-015-標高地形図出力) 標高地形図（[UR-012](../10_URD.md#ur-012)） | GeoJSON + HTML ビューア（[UR-006](../10_URD.md#ur-006)） |
|---|---|---|
| 目的 | 解析データの読み込み正常性の妥当性確認 | サミット候補・コル座標・プロミネンスの精密な目視検証 |
| 精度 | 長辺 6000px 縮小のため細部確認は不可 | 地図上での精密な確認 |
| NODATA 識別 | 識別不可（海面・負標高・NODATA がすべて 0m に統一済み）。気付きレベルの確認に留まる | GeoJSON で別途確認可 |
| 生成タイミング | 解析開始前（[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) 完了直後） | 解析完了後 |

## Alternatives

**1. [UR-006](../10_URD.md#ur-006) に統合する（却下）**:
[UR-006](../10_URD.md#ur-006) の主旨は「地図上での精密な目視検証」であり、[FR-015](../20_SRS.md#fr-015-標高地形図出力) の「解析データの読み込み正常性確認」とは目的が異なる。両者を一つの UR にまとめると、役割の異なる 2 機能を同一要件で管理することになり、URD の表現力が下がる。

**2. SRS から [FR-015](../20_SRS.md#fr-015-標高地形図出力) を除外する（却下）**:
解析前に標高データの読み込みを目視確認できることは実務上の有用性が高い。機能の存在意義は明確であるため、SRS から除外することは適切でない。[UR-012](../10_URD.md#ur-012) として要件化することで、[FR-015](../20_SRS.md#fr-015-標高地形図出力) の根拠を URD レベルで確立する。

## Consequences

- [UR-012](../10_URD.md#ur-012) は「妥当性確認」という保証範囲の限定を含む:
  - 長辺 6000px 縮小により、細部の確認は不可
  - NODATA 欠損は「陸地部分なのに海と同じ色になっている」という気付きレベルの確認に留まる（縮小で潰れると気付けない場合もある）
- [FR-015](../20_SRS.md#fr-015-標高地形図出力) の「対応 UR」が [UR-001](../10_URD.md#ur-001)（ピーク網羅検出）から [UR-012](../10_URD.md#ur-012)（妥当性確認用画像）に更新される
