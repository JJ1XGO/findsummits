# 用語集

本プロジェクトで使用する用語の定義。本書を参照先として、各ドキュメント（URD/SRS/HLD/LLD等）内では略称・通称を使用してよい。

---

## 地理・メッシュ関連

| 用語（本書での表記） | 正式名称 | 説明 |
|---|---|---|
| メッシュ | 第一次地域メッシュ（第一次地域区画） | 国土地理院が定める地域メッシュのうち、約80km四方の区画。4桁の数値コードで識別される（例: 5339）。本プロジェクトの解析単位。 |
| Keyコル | キーコル | あるピークのプロミネンスを規定するコル（鞍部）。当該ピークから任意方向に進んだとき、最初に到達する最低鞍部のうち最も標高の高いもの。 |
| プロミネンス | 比高 | ピークの独立性を示す指標。ピーク標高とKeyコル標高の差。本プロジェクトでは 150m 以上を申請対象とする。 |
| サミット | 山頂 | SOTAの対象となる山頂。本プロジェクトではプロミネンス 150m 以上のピークを指す。 |

## データソース関連

| 用語 | 説明 |
|---|---|
| DEM5a / DEM5b / DEM5c | 国土地理院の5mメッシュ数値標高モデル。5aが最優先、なければ5b、5cの順でフォールバック。 |
| DEM10b | 国土地理院の10mメッシュ数値標高モデル。DEM5が取得できない場合の最終フォールバック。 |
| 標高タイル | 国土地理院が提供するWebメルカトル図法のタイル形式標高データ（ズームレベル15、256×256px PNG）。 |
| SOTA | Summits On The Air。アマチュア無線の運用活動。本プロジェクトはSOTA日本支部（JA）の山岳リスト更新申請を目的とする。 |
