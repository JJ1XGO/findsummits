## 重要な実装メモ

### BORDER_TILES方式
```c
#define BORDER_TILES 8   // 約10km。日本のSOTA 150m突出のKeyColはほぼ収まる
```
- 解析範囲: 中心メッシュ + 周囲8タイルパディング
- 3×3フルメッシュ方式は96GBのRAMが必要→断念
- 範囲外=SEA(0)扱い。is_tile_top=1フラグで「Keyコルが範囲外」を識別

### タイルパス形式
```
{base}/{z}/{x}/{y}_{dem}.png
例: /mnt/findsummits/tiles/15/28674/12913_a.png
    /mnt/findsummits/tiles/14/14337/6456_b.png  (dem10b)
```

### CSV出力列
```
peak_lat,peak_lon,peak_elev,col_lat,col_lon,col_elev,prominence,is_tile_top
```
- is_tile_top=1: Keyコルが解析範囲外（prominence値は参考値）
