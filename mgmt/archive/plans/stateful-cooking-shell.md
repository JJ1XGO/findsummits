# 計画: SRS 4章「- **説明**:」体裁統一

## 目的
`docs/02_SRS.md` の 4章（機能要件）で、`- **説明**:` と `**説明**:` が混在している。
`**説明**:` に統一する。

## 現状
- 正しい形式（8件）: `**説明**:` + 空行 + `  - ...`
- 修正が必要（15件）: `- **説明**:` + 空行なしで `  - ...` が直続

## 修正内容
`- **説明**:\n  - ` のパターンを `**説明**:\n\n  - ` に変換する：
1. `- **説明**:` → `**説明**:`（リストマーカー `- ` を削除）
2. 直後に空行を挿入

## 実装方法
使い捨て Python スクリプトで一括処理（前回の FR 体裁統一と同方式）。
正規表現: `^- (\*\*説明\*\*:)$` → `\1`、直後の `  - ` の前に空行を挿入。

## 対象ファイル
- `docs/02_SRS.md`（修正のみ）

## 検証
- `grep -c "^- \*\*説明\*\*:"` が 0 になることを確認
- `grep -c "^\*\*説明\*\*:"` が 23（8+15）になることを確認
- git diff で意図した変更のみであることを目視確認
