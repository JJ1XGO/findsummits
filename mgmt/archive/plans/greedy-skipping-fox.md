# FR-001 レビュー反映

## Context

`docs/02_SRS.md` の FR-001（標高タイル事前取得）に対し、ユーザーレビューで以下の指摘が出た。

- 入力欄に「ユーザ入力」として「1次メッシュコードリスト」が記載されているが、対応する 7.1.1 のタイトルが「コマンド引数（1次メッシュコード）」で不一致
- 入力の網羅性不足：本来は「日本全土１次メッシュコードリスト」（バリデーション基準）と「地理院標高タイル」（取得元・外部I/F）も入力として明示すべき
- 6.1 のタイトルに付いている「（リモート取得元）」は、6.1 が「外部I/F としての標高タイルの仕様」を定義する章であることを踏まえると過剰修飾
- 7.2 内部データ一覧の「ローカルキャッシュ（標高タイル）」という名称が冗長。FR-001 出力との命名統一が必要
- 説明セクション 1 行目「各メッシュコードについて」が、入力追加後は曖昧になる
- 不正メッシュコード（日本全土１次メッシュコードリストに含まれないコード）への挙動が未定義
- 異常系セクションの記述（`タイル取得に繰り返し失敗する場合は異常終了する`）は、直前のリトライ説明と実質重複で情報価値が低い

これらを一括反映し、FR-001 とその周辺（6.1 / 7.1 / 7.2 / 目次）を整合させる。
