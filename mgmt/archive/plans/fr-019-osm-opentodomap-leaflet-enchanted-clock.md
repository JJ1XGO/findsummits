# 計画: モックアップの位置付け明文化と SRS への必要レベル反映

## Context（なぜやるか）

`docs/mockup/viewer_mockup.html`（＋`summits_data.js`）は HTML ビューアの UI を確定させる
プロトタイプだが、SRS からは §6.6（`20_SRS.md:1466`）・§6.13（`:1524`）で
「画面サンプル」リンクとして参照されるのみで、**位置付け（プロトタイプか正式か・更新方針・
SRS/HLD/LLD との関係）が文書化されていない**。

ユーザー方針:
- モックアップを「UI を確定させるためのプロトタイプ（紙芝居レベル）」と位置付け、逐次更新して
  正しい状態に保つ。その内容を**必要レベルで** SRS（以後 HLD/LLD も）へ反映する。
- 反映範囲は **A**: 位置付けの明文化＋SRS 観測挙動の不足分のみ。配色値・マーカーサイズ・
  `maxBounds`・z-index 等の実装具体値は SRS が既に「HLD に委ねる」と明記（FR-019 だけで9項目）で
  あり、HLD/LLD 未作成の現段階では **mockup が暫定保持**。HLD/LLD 起票時に抽出する。
- サンプルデータの要修正（new/delete/change が当初設定と相違）は **ユーザーが mockup 側で対応**。
  本作業のスコープ外。

調査結果の要点（Explore 2本）:
- SRS は既にモックアップの観測可能挙動をほぼ網羅（UI の約95%が実装済みかつ FR-019 と整合）。
- `30_HLD.md`/`40_LLD.md` は未作成。
- SRS に判明している観測挙動の不足は **既定背景タイルの明示**（mockup 既定=国土地理院標準地図）程度。

**仕様優先原則との整合（重要）**: モックアップは「UI を実機で確認・確定する手段」であり、
**正は依然として SRS/HLD/LLD**。モックアップ自体は権威ではなく仕様と同期させる参照物、という
切り分けを ADR で明記する（`feedback_specs_first` / CLAUDE.md 仕様優先原則を崩さない）。

## 作業項目

### 1. ADR 新規作成: `docs/decisions/ADR-SRS-039-mockup-positioning-and-spec-reflection.md`

- 状態: 採用・実装済み / 決定日: 2026-06-27
- **Decision**:
  1. モックアップを「UI を確定させるプロトタイプ（紙芝居レベル）。逐次更新し UI の現行確定状態を表す」と位置付ける。
  2. ただし**正は SRS/HLD/LLD**。確定内容を **観測可能挙動→SRS**、**実装具体値（配色・サイズ・レイアウト・パラメータ・z-index 等）→HLD/LLD** へ抽出・記録する。モックアップは権威ではなく仕様と同期させる対象。
  3. 反映粒度の原則: SRS=「何を・どう振る舞うか」、HLD/LLD=「具体値・実装方式」。HLD/LLD 未作成の現段階では HLD 相当 UI 具体値は暫定的に mockup が保持し、HLD/LLD 起票時に抽出する。
  4. モックアップと仕様の乖離はドキュメント・実装整合性原則に従い同期する。サンプルデータ（埋め込みの例示フィーチャ）は仕様ではないため SRS 反映対象外。
- **Alternatives**: (B) HLD を今起こす＝却下（SRS 段階・段階を飛ばさない）/ (C) モックアップを正とする＝却下（仕様優先原則違反）/ (D) 位置付けを書かず現状維持＝却下（参照者が判断不能）。
- 参照: UR-006・FR-013/019/020・§6.6/§6.13。

### 2. SRS: モックアップ位置付け注記の追加（`docs/20_SRS.md`）

  「画面サンプルは UI を確定させるプロトタイプ（紙芝居レベル）で逐次更新される。正式仕様は
  §6.6・§6.13・FR-019、実装具体値は HLD/LLD が定める（モックアップは権威ではなく仕様と同期させる
  参照物）。位置付け: [ADR-SRS-039](decisions/ADR-SRS-039-...)」
- **§6.13**（`:1524`）の既存パラグラフに ADR-SRS-039 へのリンクを併記（重複説明は避け参照のみ）。

### 3. SRS: 観測挙動の不足分を補完（粒度は SRS のまま・最小限）

- FR-019 背景タイル行（前タスクで追記済み `:1105`）または §6.6 背景タイル行（`:1474`）に
  **既定=国土地理院標準地図**を明示（mockup の観測挙動。SRS 粒度内）。
- 実装時に観測挙動の抜けを最終確認し、**SRS 粒度に収まるもののみ**追記する（現時点の判明分は上記既定のみ。
  配色値・サイズ等は HLD 委譲のまま手を付けない）。
