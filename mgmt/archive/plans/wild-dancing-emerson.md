# ISSUE-075 着手プラン: FR-004/FR-014 責務分担変更 + ADR-SRS-004 更新

## Context

FR-004「メッシュ結合解析」は現状「N=3 通常モード + N≥4 広域モード」の両方を抱え、責務が複合している。一方 FR-014「独立峰のコル探索」はスタブ化されており、独立した実装を持たない（2026-06-02 ADR-SRS-004 改訂時の方針）。

この構造のままだと、ISSUE-087（SRS FR-005 ピーク候補検出のレビュー反映）の観点 L（制御フロー・オーケストレーション所在の明示）を確定できない。FR-004 が 3×3 通常モード（per-mesh パイプライン全体のオーケストレーション）と N≥4 広域モード（4 コーナーパターン生成等の独自制御）の両方を兼ねていると、「FR-005 から見た上位制御の所在」が一意に定まらないため。

そこで以下に再編する:

- **FR-004** を「3×3 メッシュ結合解析オーケストレーション」に純化（N≥4 モード記述を削除）
- **FR-014** を「広域結合解析オーケストレーション」に格上げし、4 コーナー配置（NW/NE/SW/SE）生成・対象ピーク絞り込み・早期終了を内部化（スタブ化解除）
- **ADR-SRS-004** を本方針に合わせて改訂（既存改訂運用を踏襲。Superseded + 新 ADR ではなく、決定日履歴に追記する形）

これにより per-mesh パイプライン（FR-005/006/007/016）の上位制御は FR-004 に一意に集約され、ISSUE-087 観点 L の改善方向が確定できる。
