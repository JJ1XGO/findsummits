# FR-022 入力テーブルへの N 追加（純化作業の反映漏れ修正）

## Context（なぜやるか）

先の FR-022 純化作業（ADR-SRS-027 反映、コミット済み）で、FR-022 の入力テーブルに
**解析範囲サイズ N が書き漏れていた**。

- ADR-SRS-027 §28-30: 「N は呼び出し元（FR-023）から渡される生成段階タグとして受け取る（ファイル名からの逆算禁止）」と決定済み。
- SRS FR-022 **説明文**: 「N = FR-023 から渡された生成段階タグ」と既に記述済み。
- しかし SRS FR-022 **入力テーブル**は `merged_peak.csv` の1行のみで N が無い。

出力 `key_col_unresolved_peaks-<N>.csv` のファイル名タグを決めるには N を受け取る必要があり、
入力テーブルへの N 追加が必須。ADR と説明文は正しいので、修正は入力テーブル1行追加のみ。

## 網羅確認結果（他 FR に同様の漏れはないか）

「呼び出し元から引数（N／解析識別子）を受け取る」全 FR の入力テーブルを精査した。
漏れは **FR-022 の N のみ**:

- FR-014: 解析範囲サイズ N → L464 明記 ✅
- FR-015: 解析識別子 → L569 明記 ✅
- FR-007: 解析識別子・対象ピーク座標リスト → L647-648 明記 ✅
- FR-016: 解析識別子 → L695 明記 ✅
- FR-023: N は内部所有（入力に無いのが正）✅
- FR-008 / FR-018: N を受け取らない設計（接頭辞 glob 判別）✅
- **FR-022: 解析範囲サイズ N が入力テーブルに無い ❌（本修正の対象）**

## 修正内容（docs/20_SRS.md FR-022 入力テーブルのみ）

FR-022 入力テーブル（L470 付近、`merged_peak.csv` 行の下）に以下を1行追加する。
FR-014 の N 行（L464）と書式を揃え、値域・意味の差分のみ反映する:

```
| 解析範囲サイズ N（生成段階タグ） | 内部トランザクション | 必須 | — | 3・4・5・6 のいずれか。[FR-023](#fr-023-解析パイプライン制御) が明示引数として渡す。出力 `key_col_unresolved_peaks-<N>.csv` のファイル名タグに使用（その一覧を生成した段階のウィンドウサイズを表す。ファイル名からの逆算禁止） |
```

FR-014 との差分:
- 値域: FR-014 は `4・5・6`（広域専用）。FR-022 は `3・4・5・6`（フェーズ2 の 3×3 完了後 N=3 を含む）。
- 用途: FR-014 は「これから実行する窓サイズ」、FR-022 は「直前に完了した段階＝出力ファイル名タグ」。同一ループ内で FR-023 は同じ N 値を FR-014→統合→FR-022 の順に渡す。

ADR-SRS-027・ADR-SRS-019/004・FR-014 本文・3.3.x は変更不要（既に整合）。
