# FR-005/006 出力データ分類の修正（ISSUE-084 + ISSUE-083 の FR-005/006 分）

## Context

ユーザーが SRS の「FR-005: ピーク候補検出」の**出力**が未修正であることに気づいた。
調査の結果、2 件の未対応 ISSUE が該当する:

- **ISSUE-084**（種別判定・未対応/低）: ピーク候補リスト・コル情報を「内部データ」のままにするか、解析範囲結合画像と同様に「内部トランザクション」へ分類し直すかの検討
- **ISSUE-083**（形式欄整理・未対応/低）: 入出力テーブルの「形式」欄を「ファイル形式・データ型のみ」に統一し、特性記述を「備考」へ移す（全 FR 対象。今回は FR-005/006 分のみ先行処理）

FR-005 の本文・説明欄は ISSUE-087（対応完了）で整備済み。残るのは上記 2 点。
ユーザー確認で「両方（種別判定 + 形式欄整理）」を対応すると合意済み。

## 判定（ISSUE-084）: 内部トランザクション化

**結論: ピーク候補リスト・コル情報を「内部データ」→「内部トランザクション」に変更する。**

根拠:
- 前例の **解析範囲標高グリッド**（`docs/20_SRS.md:346`）は FR-015/005/006/007/016 と **5 FR にまたがる**にもかかわらず「内部トランザクション」に分類済み。「複数 FR にまたがる」ことは内部データの決め手になっていない
- ADR-SRS-017 の内部トランザクション定義「FR の入出力として一時的に発生し、メモリ上にのみ存在する値。永続化されず、独立した中央データ構造として保持されない」に、ピーク候補リスト・コル情報（メモリ上のみ・永続化されない FR 間受け渡し構造）が合致する
- 解析範囲標高グリッドと性質が同じため、一貫性の観点から内部トランザクション化が妥当

新規 ADR は不要（ADR-SRS-017 の Consequences「他 FR への適用は別 ISSUE で順次対応」の一環。ISSUE-084 がその順次対応）。

## スコープ

FR-005/FR-006 と、それに連動する FR-007/FR-016 の入力欄・SRS 7.2 一覧に限定する。
