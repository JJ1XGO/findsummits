# URD 北方領土除外の明記

## Context

SOTA日本支部の既存サミットリストは北方領土を含まない。1次メッシュは北方領土と日本領土が混在するメッシュを含む（根室・羅臼など）ため、メッシュ数（176）は変えず、URD に「北方領土のサミット候補は対象外」という地理的制約を明記する。除外の実装方法（行政区ポリゴン活用等）は後日 SRS で規定する。
