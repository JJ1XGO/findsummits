# SRS 「ステップ／フェーズ」用語整理プラン

## Context

現状の `docs/02_SRS.md` には「ステップ1〜3」と「フェーズ1〜4・3.5」という 2 層の区切りが混在している。これは Claude が定義なしに導入した用語で、以下の問題がある:

1. **一般用法（フェーズ ⊃ ステップ）と逆**: 現状は「ステップ ⊃ フェーズ」の包含関係
2. **ステップ層の意味が薄い**: ステップ1 = フェーズ1（1対1）、ステップ3 は 1 行のみで FR 対応もない
3. **FR-013 の責務混在**: 「HTML ビューアを生成する仕様」と「HTML ビューアが提供する機能」が同じ FR に混在し、分かりにくい

本変更で以下を実施する:

- **ステップ層を撤廃**
- **フェーズ3.5 をフェーズ3 に内包**
- **FR-013 を 2 つに分割**: ビューア生成仕様（FR-013 残置）／ビューア機能仕様（FR-019 新規）
- **フェーズ5「申請書生成」を新設**: FR-019・FR-011・FR-012・FR-020（公開用 HTML 新規）を集約

#### 2.2 FR-013 を分割

**FR-013 残置（フェーズ4・スリム化版）** に含める範囲（行 530〜628）:

- 概要・対応 UR・入力・出力・前提条件
- GeoJSON メタデータ
- フィーチャ構成テーブル（match_status 別）
- `##### 各フィーチャのプロパティ`（Point: ピーク／コル／既存 SOTA サミット、Polygon: AZ／delete判定ゾーン、LineString: ピーク→コル／ピーク→SOTA サミット）

→ FR-013 は「生成する HTML に埋め込むデータ構造の仕様」のみを定義

**FR-019 新規（フェーズ5 先頭）** に切り出す範囲（行 630〜668）:

- `##### HTML ビューア仕様` セクション全体
  - HTML テンプレート同梱・GeoJSON 埋め込み方式・CDN ライブラリ
  - 背景タイル切り替え・帰属表示
  - 標高バンド色・未確定フラグ警告色・delete判定ゾーンレイヤー
  - 山岳名入力 UI・rationale 編集 UI
  - localStorage による状態保持
  - 申請書エクスポートボタン（FR-011 への導線）
  - 公開用エクスポートボタン（FR-020 への導線）

新規 FR-019 の骨子:

```markdown
#### FR-019: HTML ビューア機能仕様

- **対応 UR**: [UR-006](01_URD.md#ur-006)
- **概要**: FR-013 で生成された `merged_viewer.html` がブラウザ上で提供する機能（マップ表示・編集 UI・localStorage・エクスポート機能）の仕様を定義する。
- **入力**: `merged_viewer.html`（FR-013 出力）に埋め込まれた GeoJSON データ
- **出力**: ビューア上のユーザー操作に応じた表示・編集状態・各エクスポート（FR-011/012/019 経由）
- **詳細**: （現 FR-013 の「##### HTML ビューア仕様」セクション全体を移動）
```

#### 2.4 新規 FR-020: 公開用 HTML ビューア生成 を追加

フェーズ5 末尾に追加。骨子:

```markdown
#### FR-020: 公開用 HTML ビューア生成

- **対応 UR**: [UR-006](01_URD.md#ur-006)（要 URD 確認・必要なら追加）
- **概要**: ローカル HTML ビューア（FR-013）上の「公開用エクスポート」ボタンで、外部公開用の閲覧専用 HTML を生成しブラウザダウンロードする。
- **入力**: ローカル HTML ビューアに埋め込まれた `merged.geojson` データ + localStorage の編集内容
- **出力**: 公開用 HTML ファイル（ブラウザダウンロード経由）
- **詳細**:
  - 公開用は閲覧専用（編集 UI なし・XLSX エクスポートなし・localStorage 不使用）
  - GeoJSON データを HTML に埋め込み、自己完結型とする
  - 受領側が QGIS 等で独自確認できるよう、GeoJSON ダウンロードボタンを含む
  - 詳細仕様は [6.12 出力: 公開用 HTML](#612-出力-公開用-html閲覧専用ブラウザダウンロード) を参照
```
