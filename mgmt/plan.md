# spec-panel 強化計画（2026-06-28 handover の学び反映）

## Context

2026-06-28 は `/spec-panel` を使った SRS レビューが集中的に行われ（当日 handover 22 本）、
多数の「学び」が蓄積された。その一部は既にスキル本体（`.claude/commands/spec-panel.md`）へ
反映済みだが、**未反映で再発防止に有効な観点**が残る。本計画はそれらをスキルへ反映し、
次回以降のレビュー網羅性を底上げする。ユーザー確認の結果、レビューチェック4件＋スキル本体の
保守性対応（セクション番号の役割名主化）の**全件反映**で確定。

対象ファイル: `/workspace/.claude/commands/spec-panel.md`（プロジェクト配下のスキル定義・1ファイル）

## 既に反映済み（再追加しない）

横串比較 / 台帳逆引き / 修正履歴の横展開 / 多重定義の整合 / 手順と終了条件の分断 /

## 反映内容（確定）

### A. 手順2 のチェック箇条書きへ新項目を3件追加

1. **廃止/改訂用語の残存チェック（必須）** — 出典 handover 1748
   - 趣旨: ADR で廃止・改訂された用語/決定（例: ADR-SRS-033 の廃止）が、文書全体に古いまま
     残存していないかを `grep` で能動的に検査する。
   - 「修正履歴の横展開」が *兄弟要素の同種欠陥の再発* を見るのに対し、これは *廃止決定の
     追従漏れ（古い用語の残骸）* を文書横断で見る、という差分を1行で明記する。

2. **値域/enum の参照元↔定義元 完全性チェック（必須）** — 出典 handover 1734
   - 趣旨: ある値域（例: `stability` の取りうる値）について、参照元 FR が N 値を参照し
     定義元 FR が M 値しか定義しない、という不整合を検出する。参照元・定義元の**両方**を
     開かないと値域の完全性は検証できない旨を明記。

3. **暗黙のフォールバック/デフォルト挙動の明示化チェック** — 出典 handover 1748
   - 趣旨: `area_complete` フォールバックのような暗黙のデフォルト挙動が、不備ゲート条件等と
     対応付けて明示されているかを確認し、合意境界の曖昧さを顕在化させる。

### B. 既存「多重定義の整合チェック」項を強化 — 出典 handover 1313, 1706

- 推奨対応に **「正本（canonical）を1箇所に定め、他は参照に統一せよ」** を追加（矛盾の検出に
  留めず、構造的な再発防止策まで踏み込む）。
- クロスチェック観点を追記: **ADR が定義する型/座標系/フィールド名**（例: ADR で「ピクセル座標」と
  定義 vs 本文で `col_lat/col_lon` という緯度経度フィールド名）と、本文での実際の使用形態の
  ズレを照合する。

### C. スキル本体の保守性対応（番号の役割名主化）— 出典 handover 1540

- 現スキルに残る SRS セクション番号直書き（手順2 の `§7.2.1 内部データ一覧`・`§6.1 外部I/F一覧`、
  視点2 の `§6 外部I/F一覧` 等）を、**役割名（見出しキーワード）主・番号は補足**の表記へ修正。
  - 例: `§7.2.1 内部データ一覧・§6.1 外部I/F一覧`
    → `「内部データ一覧」（§7.2.1 等）・「外部I/F一覧」（§6.1 等）`
- 理由: SRS の §6/§7 は頻繁に再構成され（当日だけで3回）、番号直書きは陳腐化する。役割名主なら
  `grep` で追え、スキルと SRS の同期負担を下げる。

## 設計上の注意（肥大化回避）

- 新項目は既存項目の文体（「**名称（必須/任意）**: 趣旨…」）に合わせ、各2〜3行に収める。
- 既存チェックと意味が重なる箇所は「○○との差分」を1行添え、重複と誤認されないようにする。
- 必須/任意の濃淡を付け、過剰な必須化はしない（廃止用語残存・値域突合は必須、暗黙
  フォールバックは任意寄り）。

## 検証

1. 編集後 `make lint`（lint-md）で警告ゼロを確認。
2. スキル更新はドキュメント扱いに準じ、更新ターン内に Conventional Commits でコミット
   （`docs(spec-panel): …` 等。push は別途指示まで不要）。
3. 実効性は次回 `/spec-panel` 実行時に観察（本計画では反映までを範囲とする）。
