# FR-015: 標高地形図出力 レビュー反映プラン

## Context

SRS の FR-015（標高地形図出力）について、対応 UR の妥当性・記述重複・用語使用・データ分類・色分け仕様の所在など 10 観点をレビュー。決着内容を SRS/URD/ADR/CLAUDE.md に反映する。

このレビューの主な狙い:
- FR-015 を「ユーザー成果物としての標高地形図 PNG」として正しく位置付ける（観点 A・J）
- データ分類・用語・参照リンクの一貫性を上げる（観点 G・H・I）
- 色分け仕様を SRS で確定し、HTML ビューアと同様のユーザー I/F として扱う（観点 J）

レビューでは「仕様優先原則」（コードと SRS の乖離は意図的・正常）を踏まえつつ、ユーザーの明示指示により現状コードの色分けロジック（Japan Topo スキーム）を SRS の色分け仕様として確定する方針を採用。

**ADR（`docs/decisions/ADR-URD-015-<slug>.md`）**: 新規作成
- 背景: FR-015 の用途（解析データの妥当性目視確認）に対応する UR が URD に欠けていた

### 観点 B: 6.8 セクションタイトル変更

- `### 6.8 出力: 標高地形図（Terrain-RGB PNG）` → `### 6.8 出力: 標高地形図`

### 観点 C: FR-015「説明」セクションの中粒度化

現状 3 項目を以下に置換:

```
**説明**:

  - 目的: 解析に使う標高データの読み込み正常性を解析実行前に視覚確認できるようにする
  - 成果物の詳細仕様（ファイル名・形式・解像度・色分け）は [6.8](#68-出力-標高地形図) を参照
```

「結合画像」は観点 H で「解析範囲結合画像」にリネーム済みとして記述。

### 観点 D: 6.8 タイミング記述を FR ベースに

### 観点 E: NODATA 表示の扱い

- 結合画像段階で NODATA は 0m に統一済み（海・負標高と区別不可）のため、6.8 に「NODATA 表示」独立項目は **設けない**
- 観点 C の中粒度化により FR-015 の説明セクションからも NODATA 言及は削除済み

### 観点 F: 解析範囲の明示

### 観点 J: 標高レーン・色分けを SRS 6.8 で確定

**6.8 に標高レーン定義表を追加**（現状コード `mesh_analyze.c::elev_to_rgb()` ベース）:

| 標高境界 (m) | RGB | 16 進 | 用途・名称 |
|---|---|---|---|
| -6000 | (26, 79, 114) | #1a4f72 | 海洋（NODATA センチネル） |
| -1 | (91, 163, 201) | #5ba3c9 | 沿岸 |
| 0 | (232, 245, 200) | #e8f5c8 | 低地 |
| 300 | (168, 208, 141) | #a8d08d | 台地 |
| 900 | (106, 168, 79) | #6aa84f | 山地 |
| 1800 | (181, 101, 29) | #b5651d | 亜高山 |
| 2700 | (139, 115, 85) | #8b7355 | 高山 |
| 3800 | (240, 235, 227) | #f0ebe3 | 頂上 |

**補間方式・特殊ケース処理を仕様文に明記**:
- 隣接ストップ間で線形補間、3800m 以上は頂上色にクランプ
- 海面・負標高・NODATA はすべて 0m に統一済み（FR-002）→ 沿岸色（-1m 扱い）で表示
- 出典「Japan Topo」スキーム（`docs/decisions/research/dem_colormap.html`）を脚注で明示

**モックアップ画像の提示**:
- 既存の標高地形図 PNG（例: `$DATA_DIR/images/5339_terrain.png` の縮小サンプル）を `docs/figures/` に配置し SRS 6.8 から参照
- ファイル名・配置は実装段階で確定

**実装の外出し方針**:
- C コード（`src/mesh_analyze.c::elev_to_rgb()`）内のハードコードを外出しし、SRS で定義された値を実装側が参照する形に
- 外出しの具体形式（設定ファイル / 専用ヘッダー / JSON 等）は HLD/LLD マター
- 今回の SRS 修正には実装変更は含めない（ISSUE として別途登録）

## 検証方法

SRS レビューの修正なので、ビルド・テスト実行は不要。検証は以下のドキュメントレビューで実施:

1. **整合性検証**:
   - `grep -nE "結合画像" docs/20_SRS.md` で「解析範囲結合画像」への置換漏れがゼロであることを確認
   - `grep -nE "Terrain-RGB" docs/20_SRS.md` で 6.8 タイトルからの除去確認
   - `grep -nE "結合画像" docs/20_SRS.md | grep "内部データ"` で残存ゼロ確認（観点 H）
   - 7.2 内部データ一覧から「結合画像」行が削除されていることを目視確認

2. **リンク機能検証**: GitHub の SRS ページで FR-015 と 6.8 のリンクをクリックして遷移確認

3. **UR-012 整合**: FR-015「対応 UR」リンクが UR-012 に遷移すること、UR-012 から関連 ADR-URD-015 が参照できること

4. **モックアップ画像**: SRS で参照する `docs/figures/` 配下の画像が GitHub 上で正しく表示されること

5. **CLAUDE.md 追記検証**: 「ドキュメントフォーマット標準」セクションにリンク化方針・形式欄方針が追記されていること
