# ISSUE-083: SRS 全 FR 出力テーブル「形式」欄の一括見直し

## Context

`docs/CLAUDE.md` のフォーマット標準では「入出力テーブルの『形式』欄はファイル形式・データ型のみを記載する。特性記述（解像度・色分け・データ範囲等）は『備考』欄に記載する」と定めている。SRS の出力テーブルにはこの標準に反し、形式欄にファイルパス・RFC 標準・座標参照系・配布方法・件数・分割粒度などの特性記述が混入している箇所が残っている。

FR-017〜FR-015（記載順）はユーザーが「データ型で具体的に書く」スタイルで統一済み。残りの未統一 FR を同スタイルに揃え、混入した特性記述を備考欄へ移すのが本対応のゴール。

### 確定した方針（ユーザー確認済み）

- **形式欄は「データ型で具体的に」書く**。値の意味・構造（`2次元配列`・`文字列`・`…のリスト`・`メッシュコード集合＋座標対応`）は形式欄に残してよい
- **FR-005/006 の `メモリ上のデータ構造`（ISSUE-084 で先行設定）は基準にしない**。今回データ型で具体的に書き直す（修正対象に含める）
- **単位（`浮動小数（m）` の m）はデータ型の一部として残す**（既統一実例 FR-003/004 に倣う）
- 件数・ファイル分割粒度・パス・RFC・座標参照系・配布方法・列構成 などは備考へ移す
- **FR-010・FR-019 は今回対象外**。形式欄が「リンク列記／フィルタ機能の説明」で、特性記述の移動とは別種の問題（形式欄の意味論）のため、それぞれ個別 ISSUE を起こし各レビュー時に検討する
