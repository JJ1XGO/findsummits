# ISSUE-075 着手プラン: FR-004/FR-014 責務分担変更 + ADR-SRS-004 更新

## Context

FR-004 は現状「N=3 通常モード + N≥4 広域モード」の両方を抱えており、責務が複合している。これを以下に再編する:

- **FR-004** を「3×3 メッシュ結合解析オーケストレーション」に純化（N≥4 モード記述を削除）
- **FR-014** を「広域結合解析オーケストレーション」に格上げし、4 コーナー配置（NW/NE/SW/SE）生成を内部化
- **ADR-SRS-004** を本方針に合わせて再更新（max pooling 採用の技術判断は維持・責務分担変更を反映）

### この再編が ISSUE-087 の前提である理由

2026-06-09 セッションで FR-005 のレビュー観点を整理した際、ユーザー指摘により観点 **L（制御フロー・オーケストレーション所在の明示）** が浮上した。L の改善方向は FR-004 にオーケストレーション役割を集約することを含むため、FR-004 の責務再編が完了していないと FR-005 観点 L/M/N の結論が暫定的にしかならず手戻りが発生する。

そのため作業順序を「ISSUE-075 完了 → ISSUE-087（FR-005 レビュー反映）着手」とした。

## 実行ステップ

1. ADR-SRS-004 の現状把握（max pooling 採用の技術判断は維持）
